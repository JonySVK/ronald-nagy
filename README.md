## Reuse this project as a template

1. On GitHub, fork or clone this repository.
2. In **index.html**, replace Ronald's name, page title, introduction, biography, location, Buy Me a Coffee link, and Instagram link with your own details.
3. In **assets/script.js**, update the photographer name used in the images' accessible alt text.
4. Replace the image files in **photos**. Keep the numbering paired:
   - **1.png** to **10.png** are the full-size images opened in the slider.
   - **1-reduced.png** to **10-reduced.png** are the gallery previews. Keep the same subject and number as each full-size image; previews should have a longest side of about 1200 px.
5. In **assets/style.css**, edit the color variables at the top of the file to match your style.
6. Update or remove the footer credits in **index.html**.

This is a static site: no build tools or dependencies are required. The page preloads all reduced previews and loads each full-size image when it is opened in the slider.

## Run locally

Open **index.html** in a web browser.

## Project files

- **index.html** — page content and links
- **assets/style.css** — layout, colors, and responsive styles
- **assets/script.js** — photo gallery, loading screen, and slider
- **photos/** — numbered full-size photographs and reduced previews
